# Privacy — Action Plan V1

**Estado:** Aprobado

## Decisión

Action Plan V1:

- se muestra únicamente para priorities accionables;
- utiliza un catálogo determinístico;
- no utiliza IA generativa;
- entrega primeros pasos, no una solución completa;
- `validation_step` representa una comprobación orientativa;
- no certifica cumplimiento;
- no determina la necesidad jurídica de consentimiento;
- no modifica automáticamente el sitio;
- solo utiliza evidencia pública minimizada;
- mantiene un máximo de tres prioridades visibles;
- está diseñado como base del ciclo:

Diagnóstico → Acción → Revalidación
