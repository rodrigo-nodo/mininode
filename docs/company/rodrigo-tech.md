# Rodrigo Tech - Modelo operativo

## Propuesta

**Diseñamos e implementamos soluciones de tecnología, datos e IA.**

Ámbitos principales:

- Arquitectura
- Datos
- IA
- Diagnóstico
- Asesoría
- Implementación

## Cómo trabajamos

**Entender el problema → diagnosticar → diseñar la solución → armar el equipo adecuado → implementar.**

Rodrigo Tech funciona como una **firma de tecnología que arma la solución y utiliza una red de especialistas para ejecutarla**.

## Decisión societaria

Rodrigo Tech se proyecta como una **sociedad separada de Rodrigo Hub** cuando exista el primer negocio real que justifique operar con clientes y Delivery Partners.

La razón principal no es tributaria. Es de **separación de riesgo y claridad de negocio**:

- Tech asume contratos de proyectos;
- puede comprometer alcance, plazo y calidad;
- subcontrata o coordina Delivery Partners;
- puede enfrentar riesgos de ejecución, confidencialidad, propiedad intelectual y responsabilidad profesional;
- estos riesgos no deberían mezclarse innecesariamente con los activos propios de Hub.

## Rol de Rodrigo Tech

Rodrigo Tech se encarga de:

- venta;
- relación con el cliente;
- diagnóstico;
- diseño de la solución;
- arquitectura;
- gestión del proyecto;
- riesgo;
- QA y control de calidad.

## Delivery Partner

El **Delivery Partner** es el especialista que ejecuta el trabajo técnico.

La red puede incluir especialistas en:

- datos;
- IA;
- cloud;
- desarrollo;
- ciberseguridad;
- UX;
- otras tecnologías.

Rodrigo Tech arma el equipo adecuado según cada proyecto.

## Modelo económico de referencia

Como referencia inicial:

**70% Delivery Partner / 30% Rodrigo Tech**

La base de cálculo es el **ingreso neto del proyecto**:

- sin IVA;
- descontando costos directos extraordinarios previamente acordados.

No es una regla rígida. Cada proyecto puede ajustarse según esfuerzo, riesgo y responsabilidad de cada parte.

## Forma preferida de cotizar

Ejemplo:

| Concepto | Monto |
|---|---:|
| Delivery Partner - ejecución | $6.000.000 |
| Rodrigo Tech - comercial + arquitectura + gestión + riesgo + margen | $3.000.000 |
| **Precio al cliente** | **$9.000.000 + IVA** |

Este formato permite separar claramente el valor de la ejecución del valor que agrega Rodrigo Tech al estructurar, vender y gobernar la solución.

## Principio

Rodrigo Tech no vende simplemente horas de especialistas.

**Rodrigo Tech entiende el problema, diseña la solución, arma el equipo adecuado y responde por la implementación.**
