# Rodrigo Hub - Empresa inicial

## Decisión actual

**Rodrigo Hub SpA** será la primera sociedad a constituir.

Su propósito es **crear, operar y hacer crecer productos digitales propios**, incluyendo SaaS y agentes.

## Alcance

Estructura inicial:

```text
RODRIGO HUB SpA
│
├── Privacy Web
├── Privacy Data
├── futuros SaaS
└── futuros agentes
```

Privacy Web y Privacy Data son productos de segundo nivel dentro de Hub. No se crea por ahora una sociedad ni una capa adicional llamada Privacy.

## Por qué partir por Hub

Hub puede operar inicialmente de forma simple y directa:

- productos propios;
- código y propiedad intelectual propios;
- clientes y suscripciones propias;
- infraestructura digital;
- costos de cloud, API y marketing;
- sin necesidad inicial de Delivery Partners.

Además, mantener Hub separado de Tech ayuda a aislar los activos escalables de Hub del riesgo contractual propio de proyectos de consultoría e implementación.

## Activos que conviene mantener identificables por producto

Aunque todos los productos vivan inicialmente dentro de Rodrigo Hub SpA, conviene que cada uno mantenga identificables:

- código;
- marca;
- dominio o ruta;
- clientes;
- ingresos y MRR;
- costos directos;
- documentación;
- contratos;
- propiedad intelectual.

Esto facilita evaluar, financiar, separar o vender un producto en el futuro.

## Contabilidad interna

Aunque exista una sola sociedad, se recomienda llevar análisis por producto o centro de resultado, por ejemplo:

- Privacy Web
- Privacy Data
- SaaS 3
- Agente 1

Así se puede conocer el P&L (Profit & Loss / Estado de Resultados) de cada producto.

## Relación con Rodrigo Ventures

Por ahora, **Rodrigo Ventures** funciona como paraguas corporativo/comercial y no como una sociedad adicional.

```text
RODRIGO VENTURES
       │
      HUB
       │
 ┌─────┴─────┐
Privacy Web  Privacy Data
```

En contratos, facturación y obligaciones legales de los productos Hub debe utilizarse **Rodrigo Hub SpA**.

## Estado

Decisión inicial para constitución y operación. El objeto social, actividades económicas, domicilio, régimen tributario, patente municipal y marcas deben validarse formalmente antes de implementación.
