# Fiscalización de datos personales - Guía interna

## Objetivo

Este documento resume, en lenguaje simple, **qué materias podría revisar una fiscalización de protección de datos** y cómo se relacionan con Privacy Web y Privacy Data.

No existe una lista única y cerrada de preguntas. La autoridad puede requerir antecedentes, documentos e información para verificar cómo una organización trata y protege los datos personales.

## Cómo se complementan los productos

Privacy Web y Privacy Data son productos distintos y complementarios.

### Privacy Web - lo público

Revisa principalmente lo que una organización muestra o expone hacia afuera:

- transparencia;
- formularios;
- cookies;
- contacto;
- seguridad visible.

### Privacy Data - lo interno

Ayuda a entender y ordenar cómo el negocio maneja los datos por dentro:

- datos;
- usos;
- terceros;
- accesos;
- conservación;
- seguridad;
- derechos;
- evidencia.

## Lectura conjunta

```text
                 LEY / FISCALIZACIÓN
                         │
              ¿Puedes explicar y demostrar
               cómo manejas los datos?
                         │
              ┌──────────┴──────────┐
              ↓                     ↓
        PRIVACY WEB            PRIVACY DATA
         lo público              lo interno
```

El objetivo futuro no es que un solo producto responda todo, sino que **Privacy Web + Privacy Data ayuden a preparar una respuesta más completa**.

## Principio de producto

No presentar esta guía como una lista exacta de preguntas que hará la autoridad.

La formulación recomendada es:

> **Si fiscalizan tu negocio, ¿qué podrían revisar?**

Y la promesa de producto debe mantenerse prudente:

> **Privacy Web y Privacy Data ayudan a identificar, ordenar y respaldar información relevante. No constituyen una certificación legal ni garantizan cumplimiento.**
